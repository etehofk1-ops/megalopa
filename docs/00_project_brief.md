# Megalopa Project Brief

Megalopa는 OpenCrab ontology pack이 사람이 읽거나 에이전트 추론에 투입되기 전에 신뢰 가능한 사용 범위를 평가하는 QA 레이어다.

## Positioning

Megalopa는 진리 판정기가 아니다. 입력 팩의 근거, 출처, 구조, 관계 강도, 편향 명명, 추론 안전성을 분석해 사용 위험도를 리포트한다.

## MVP Scope

1. JSON/YAML pack input
2. node, edge, evidence parsing
3. schema consistency validation
4. unsupported edge and missing evidence detection
5. strong relation warning
6. bias naming warning
7. reliability score and risk level
8. Markdown report
9. clean SaaS frontend
